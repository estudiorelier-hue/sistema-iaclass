# Catálogo de skills

O que cada skill instalada faz e quando usar. Você não precisa chamar pelo nome: descreva o que quer e o Claude
escolhe. Chamar pelo nome (`/nome`) serve quando você quer garantir.

## As do curso

| Skill | O que faz |
|---|---|
| `comecar` | Monta o sistema: pergunta quem você é, cria só as áreas que você usa, escreve o `CLAUDE.md` e o contexto. Depois, adiciona área ou cliente. |
| `marca` | Monta o design system (do zero, do manual do cliente, de um produto irmão ou de um export do Claude Design) e gera a `prova.html` pra ver no navegador. |
| `atualizar-sistema` | Traz a versão nova do curso (método, catálogos, skills) sem tocar no que é seu. |

## Cara certa: tirar a cara de I.A de página e interface

| Skill | O que faz | Precisa |
|---|---|---|
| `design-taste-frontend` | Lê o briefing, decide a direção e constrói landing, portfólio ou redesign sem o visual genérico de I.A. | nada |
| `design-taste-frontend-v1` | A versão anterior da mesma skill, mantida pra quem já tinha projeto nela. Use a atual. | nada |
| `hallmark` | Página nova, auditoria de design, redesign, e extrair o design de um site ou print pra reproduzir. | nada |
| `gpt-taste` | Interface e movimento com GSAP, com variação de layout pra não sair tudo igual. | nada |
| `stitch-design-taste` | Escreve um `DESIGN.md` pro Google Stitch, quando você desenha lá. | nada |

## Movimento

| Skill | O que faz | Precisa |
|---|---|---|
| `motion-dev-animations` | Animações suaves com mola (Motion.dev) em site simples, React ou Next. | Node, no projeto |

## Design system, marca e peças

| Skill | O que faz | Precisa |
|---|---|---|
| `design-system` | Tokens em três camadas (base → papel → componente), variáveis CSS, escalas de espaço e tipo, especificação de componentes. O `/marca` usa por dentro. | nada |
| `brand` | Voz da marca, identidade visual, mensagens, consistência. | nada |
| `design` | Logo, identidade completa, ícones, banners, fotos pra rede social. | chave da Gemini, Python |
| `banner-design` | Banners pra rede social, anúncio, site e impresso, com opções de direção de arte. | chave da Gemini |
| `canvas-design` | Arte visual em PNG e PDF (capa, pôster, peça gráfica), sem foto. | nada |
| `slides` | Apresentações em HTML com gráficos e os tokens da marca. | nada |
| `ui-styling` | Interfaces com shadcn/ui e Tailwind, pra sistemas em React. | Node, Python |
| `ui-ux-pro-max` | Referência de estilos, paletas e pares de fonte pra web e celular; ajuda a decidir o visual. | Python |

## Construir e conferir

| Skill | O que faz | Precisa |
|---|---|---|
| `web-artifacts-builder` | Páginas e apps em HTML com vários componentes, empacotados num arquivo só. | Node, Playwright |
| `webapp-testing` | Abre o site ou sistema num navegador invisível, tira print, testa botão e formulário. | Python, Playwright |
