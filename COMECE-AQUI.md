# Comece aqui

Este é o seu sistema do IA CLASS: uma pasta em que o Claude Code conhece você, guarda cada coisa no lugar certo e
tem as skills do curso instaladas. Tudo que você criar no curso vai morar aqui.

## O primeiro dia, em quatro passos

1. **Abra esta pasta no Claude Code.** No VS Code: Arquivo → Abrir pasta → escolha a pasta que você baixou
   (`sistema-iaclass`, ou `sistema-iaclass-main` se veio pelo botão Download ZIP do GitHub). No terminal: entre na pasta
   e digite `claude`. O curso ensina a instalar os dois.
2. **Peça `/comecar`.** São umas oito perguntas, uma por vez, e dez minutos. No fim, o Claude escreve quem você é no
   `CLAUDE.md`, cria só as áreas que você vai usar e, se você tiver material de marca, já chama o `/marca`.
3. **Faça o primeiro pedido.** O `/comecar` termina propondo um. Se preferir, peça qualquer coisa do seu dia: um texto,
   uma pasta de cliente, um orçamento.
4. **Quando tiver algo pra construir** (site, landing page, linktree, sistema), escreva o pedido antes, do jeito que
   o curso ensina: o método está em `sistema/metodo/metodo.md` e o modelo em `sistema/metodo/pedido-modelo.md`. Mande o
   pedido e o que precisar junto (foto do rascunho, referências). Pedido bom, resultado bom.

## As skills do curso

| Skill | Quando usar |
|---|---|
| `/comecar` | montar o sistema; depois, adicionar uma área (`/comecar vídeos`) ou um cliente (`/comecar cliente Ana`) |
| `/marca` | montar ou atualizar o design system, seu ou de um cliente |
| `/atualizar-sistema` | trazer a versão nova do curso sem mexer no que é seu |

As outras skills instaladas (design, movimento, imagens, slides, testes) estão explicadas em
`sistema/catalogo-skills.md`. Algumas precisam de ferramentas no computador: `sistema/ferramentas.md`.

## Três regras que fazem diferença

- **Uma tarefa por conversa.** Terminou, abra outra (`/clear`). O Claude fica mais rápido e mais barato.
- **Jogue tudo na `entrada/`.** Print, PDF, áudio, referência. Não organize; o Claude organiza.
- **Corrija uma vez.** Quando ele errar o seu jeito, diga "prefiro assim" e deixe salvar. Não repete mais.
