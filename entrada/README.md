# Entrada

Jogue aqui tudo que vier de fora: prints, PDFs, áudios, planilhas, briefings, referências, fotos.
Não precisa organizar. Quando você pedir algo que use um desses arquivos, o Claude lê daqui e, ao terminar,
leva o arquivo pra pasta certa (a área ou o cliente a que ele pertence) e te avisa onde ficou.

Pra esvaziar tudo de uma vez, peça: "arruma a entrada".
