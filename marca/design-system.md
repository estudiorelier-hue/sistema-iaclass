# Design system

As decisões de design num lugar só. O Claude lê este arquivo antes de construir qualquer coisa visual:
site, carrossel, proposta, slide, vídeo, imagem.

## Cores e o papel de cada uma
| Papel | Cor | Onde usa |
|---|---|---|
| Fundo | `#FFFFFF` | o fundo de tudo |
| Fundo alternativo | `#F5F5F7` | blocos que precisam se separar |
| Tinta | `#1D1D1F` | texto principal |
| Tinta secundária | `#6E6E73` | apoio, legendas, metadados |
| Destaque | `#0A6CFF` | uma ação por tela: o botão principal, o link |
| Sobre o destaque | `#FFFFFF` | texto em cima do destaque |
| Linha | `rgb(0 0 0 / .08)` | divisórias e bordas |

## Fontes
- **Títulos:** a fonte do sistema (sem serifa), peso 700, espaçamento entre letras levemente negativo.
- **Texto:** a fonte do sistema, peso 400, 16 px, entrelinha 1,5.

## Espaço
Escala de 4 px: 4, 8, 12, 16, 24, 32, 48, 64, 96. Margem lateral mínima de 16 px no celular e 40 px no computador.
Cantos arredondados: 12 px.
